# Seguidores-No-Seguidos-de-Instagram
Programa en C++ para generar una lista con las personas que sigues en Instagram pero no te siguen 

# Pasos:
1. Obtener los datos desde Ajustes > Centro de cuentas > Tu información y permisos > Exportar tu información > Descargar o transferir información. Seleccionar solo "Seguidores y seguidos", sin filtrar por fecha, y formato **JSON**.
2. Descomprimir los archivos y coger `followers_1.json` y `following.json`.
3. Poner esos dos archivos en la misma carpeta que el ejecutable, con esos nombres exactos.
4. Ejecutar el programa.
5. El resultado está en `SeguidosNoSeguidores.txt`.
